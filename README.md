# Project Redoubt

## Zero-Trust Enterprise Security Architecture & Attack-Resilience Lab

Project Redoubt is a security architecture laboratory built around a fictional enterprise named **ResTech**.

The purpose of the project is to design, implement, test and document a modern enterprise security architecture using Zero Trust principles.

The project will demonstrate security architecture across:

- Identity and access management
- Zero Trust architecture
- Network segmentation
- Application security
- Workload identity
- Data protection
- Policy-as-code
- Secrets management
- Security monitoring
- Detection engineering
- Threat modelling
- Adversary simulation
- Incident response
- Cyber resilience
- Infrastructure-as-Code

---

## Fictional Enterprise

**Organisation:** ResTech

**Industry:** Technology Research, Engineering and Digital Services

**Location:** Australia

**Workforce:** Approximately 500 employees and 50 contractors

ResTech operates a hybrid enterprise environment containing corporate endpoints, cloud infrastructure, internal applications, public applications, development environments, databases and security systems.

All people, organisations, systems, addresses and information represented by ResTech are fictional and exist solely for this security architecture laboratory.

---

## Project Objective

The primary objective of Project Redoubt is to answer:

> How can an enterprise security architecture minimise the impact of compromised identities, endpoints, applications and workloads while maintaining legitimate business access?

The architecture follows three core assumptions:

1. Verify explicitly.
2. Apply least privilege.
3. Assume compromise.
