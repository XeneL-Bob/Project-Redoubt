# Project Redoubt — Architecture References

Project Redoubt uses recognised security architecture frameworks as design references.

## NIST SP 800-207 — Zero Trust Architecture

https://csrc.nist.gov/pubs/sp/800/207/final

Used for:

- Zero Trust principles
- resource-focused security
- Policy Engine
- Policy Administrator
- Policy Enforcement Point
- continuous access evaluation concepts

## NIST SP 800-207A — Cloud-Native Zero Trust Access Control

https://csrc.nist.gov/pubs/sp/800/207/a/final

Used for:

- application identity
- service identity
- workload-level access
- identity-tier policy
- application-level policy enforcement

## NIST Zero Trust Architecture Implementation Project

https://pages.nist.gov/zero-trust-architecture/

Used as an implementation-oriented reference for Zero Trust architecture components.

---

Project Redoubt remains vendor-neutral during Phase 4.

References inform architectural principles but do not imply certification or formal compliance.
